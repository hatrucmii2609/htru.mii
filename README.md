# htru.mii

A personal portfolio website for collecting projects, experiments, and things I'm learning.

## ✦ About
This site is a small, evolving home for my work and ideas.

## 🗂 Project structure
```
htru.mii/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── .gitignore
└── README.md
```

## 🚀 Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Edit the text in `index.html` and the design in `css/style.css`.

No framework or installation required.

## 📌 To personalize
- Replace the intro text with your own bio.
- Add your real projects in the Projects section.
- Update the GitHub/contact links.
- Add screenshots or previews for finished projects.
